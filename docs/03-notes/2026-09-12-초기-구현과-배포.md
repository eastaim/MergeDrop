## 왜 필요했는가

첫 웹 게임을 "만들었다"가 아니라 "올렸다"까지 가보는 것이 목표였다. 로컬에서 도는 것과 배포본이
실제로 동작하는 것은 다른 문제라, 배포 후 실제 URL에서 플레이해보는 것까지를 완료 조건으로 잡았다.

## 실플레이로 잡은 버그

둘 다 테스트나 타입 검사로는 절대 잡히지 않고, 브라우저에서 실제로 조작해봐야만 드러나는 종류였다.

### 1. Matter 이미지에 scale 트윈 → 게임 루프 전체 정지

머지로 생긴 과일에 "톡 튀어나오는" 연출로 scale 트윈을 걸었다.

```ts
image.setScale(0.6);
this.tweens.add({ targets: image, scale: 1, duration: 140 });  // ← 원인
```

Phaser의 Matter 게임오브젝트에서 `setScale`은 **물리 바디까지 스케일한다**. 갓 생긴 과일이
트윈이 끝나기 전에 다시 머지되어 파괴되면, 트윈은 계속 돌면서 사라진 바디를 참조한다.

```
TypeError: Cannot read properties of undefined (reading 'position')
```

이 예외가 requestAnimationFrame 콜백에서 터지면서 게임 루프가 통째로 멈췄다. **화면은 그냥
얼어붙기만 하고 아무 표시도 없어서**, 처음에는 게임오버가 잘못 걸린 줄 알았다. 공중에 뜬 과일이
두 스크린샷 사이에 1픽셀도 움직이지 않은 것을 보고 알아챘다.

부수적으로, scale 트윈은 충돌 반경까지 0.6배에서 시작하게 만들므로 게임플레이상으로도 틀렸다.

**해결**: 알파 트윈으로 교체(디스플레이 객체만 건드림) + 파괴 직전 `killTweensOf()`.

### 2. 게임오버가 영원히 발생하지 않는 조건

처음 판정은 "위험선 아래로 한 번 내려간 과일만 판정 대상(arming)"이었다. 낙하 지점이 위험선보다
위에 있어서, 갓 떨어뜨린 과일이 즉시 게임오버를 내는 것을 막으려는 장치였다.

문제는 **이미 높이 쌓인 더미 위에 바로 얹힌 과일은 선 아래로 내려갈 일이 없다**는 것이다. 즉 가장
위험한 상황일수록 무장이 안 되어 게임이 끝나지 않는다.

**해결**: "정지한 과일이 위험선 위에 있으면"으로 규칙을 바꿨다. 낙하 중인 과일은 속도가 있으므로
자연히 제외되고, 무장이라는 개념 자체가 필요 없어졌다.

### 3. (사소) `setStrokeStyle`에 알파를 색에 끼워 넣음

`setStrokeStyle(2, 0xffffff22)`로 썼는데 세 번째 인자가 알파다. 에러 없이 밝은 노란 테두리가
그려졌다. `setStrokeStyle(2, 0xffffff, 0.16)`으로 수정.

## 검증 방법 메모

콘솔 버퍼가 페이지 리로드로 지워지지 않아서, "고쳤는데 옛날 에러가 계속 보이는" 혼란이 있었다.
새로 발생한 에러만 세려면 리로드 직후 카운터를 심는 편이 확실하다.

```js
window.__errs = [];
window.addEventListener('error', (e) => window.__errs.push(String(e.message)));
```

게임오버 경로는 자연 플레이로 도달하려면 오래 걸려서, `config.ts`의 `dangerY`를 일시적으로 낮춰
검증한 뒤 되돌렸다. 튜닝 값이 한 파일에 모여 있어서 가능했던 방식이다.

## 참고사항 / 남은 이슈

- **밸런싱이 미검증이다.** 티어 테이블과 스폰 가중치는 초기값이고 실플레이 데이터가 없다.
  `game-designer` 서브에이전트로 검토할 것.
- **Actions deprecation 경고** — `actions/checkout@v4`, `setup-node@v4`, `configure-pages@v5`,
  `deploy-pages@v4`가 Node 20을 타깃해 경고가 뜬다. 배포는 정상. v5 계열로 올리면 사라진다.
- **사운드 없음** — 머지 순간의 피드백이 시각(링 이펙트)뿐이다.
- **높이 쌓였을 때의 스폰 겹침** — 더미가 낙하 지점까지 닿으면 새 과일이 기존 과일과 겹쳐 생성되어
  Matter가 튕겨낼 수 있다. 실제로는 그 전에 게임이 끝나지만, 방어 로직은 없다.
